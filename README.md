# 豆包小窗

Edge 扩展:点击工具栏图标,在独立小窗中打开豆包聊天页(https://www.doubao.com/chat/),再点一次关闭。

## 安装(开发人员模式)

1. 打开 `edge://extensions/`
2. 打开左侧「开发人员模式」开关
3. 点击「加载解压缩的扩展」,选择本文件夹
4. 点击工具栏的拼图图标,找到「豆包小窗」,点图钉固定到工具栏

## 使用

- 点击工具栏图标 → 弹出小窗(首次打开需扫码登录豆包,登录态与浏览器共享,之后免登录)
- 再点图标(或直接关窗)→ 关闭
- 快捷键 `Alt+Shift+D` 同效,可在 `edge://extensions/shortcuts` 修改

## 自定义

- 小窗大小:改 `background.js` 中的 `width` / `height`
- 打开页面:改 `background.js` 中的 `DOUBAO_URL`
- 图标:直接替换 `icons/` 下的同名 PNG

## 说明

- 非官方扩展,仅用于个人使用
- 不注入、不读取、不修改豆包页面内容,只做窗口管理
