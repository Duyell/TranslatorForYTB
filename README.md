# TranslatorForBrowser

Chrome 扩展:在 YouTube 播放器画面上叠加 **日语语音的实时中文翻译字幕**,看日语 Vtuber 录播/直播时不用再「看图猜话」。

- **字幕优先**:YouTube 有自动字幕时直接使用(免费、零延迟)
- **语音识别兜底**:没有字幕时自动切换到火山引擎实时语音识别(ASR),有声音就能出字幕,录播/直播都行(延迟约 7 秒)
- **直播聊天翻译**:评论区评论自动翻译,译文小字附在原文下方(可关)
- 翻译默认走免费 Google 接口,零配置开箱即用;也可在设置页填入任意 OpenAI 兼容 API(DeepSeek、火山方舟豆包等)
- 译文直接叠加在视频画面下方(双语可关),不遮挡控制条

## 安装

1. 打开 `chrome://extensions/`
2. 打开右上角「开发者模式」
3. 点「加载已解压的扩展程序」,选择本文件夹
4. 固定图标到工具栏;点击图标 = 开关当前 YouTube 标签页的字幕翻译(快捷键 `Alt+Shift+D`,可在 `chrome://extensions/shortcuts` 修改)
5. 右键图标 →「选项」打开设置页

## 使用

- **录播**:打开任意带日语自动字幕的 Vtuber 视频,字幕自动叠加显示(优先自动字幕,无自动字幕时用人工日语字幕)
- **直播**:打开直播(需主播开启直播自动字幕),几秒后开始滚动显示最新译文;长时间没有新字幕会淡化提示
- **无字幕的视频/直播**:自动切换到语音识别(需在设置页配置火山引擎 Key,见下),有声音就能出字幕
- 图标上的 badge 显示当前标签页的开关状态(绿「开」/灰「关」)

## 设置(右键图标 → 选项)

| 项 | 说明 |
| --- | --- |
| 翻译引擎 | 免费 Google(默认)/ 自定义 OpenAI 兼容 API |
| API Base URL / Key / 模型名 | 自定义引擎三件套。例:DeepSeek `https://api.deepseek.com` + `deepseek-chat`;火山方舟 `https://ark.cn-beijing.volces.com/api/v3` + 你的接入点 ID。Key 只保存在本机,不同步云端 |
| 显示日语原文 | 双语开关(默认开) |
| 字号 | 12–32 px,保存即生效 |
| 测试翻译 | 用当前设置实测翻译「こんにちは、世界」 |
| 语音识别 API Key | 无字幕兜底用。需在[豆包语音控制台](https://console.volcengine.com/speech/app)开通「流式语音识别-大模型」并签发 Key(**火山方舟的 Key 不通用**),按转写时长计费 |
| 识别语言 | 默认 `ja-JP`,留空 = 自动检测 |
| 翻译直播聊天 | 评论区评论翻译开关(默认开),译文小字附在评论原文下方;聊天翻译走低优先级队列,不影响字幕翻译速度 |
| 测试识别 Key | 发一段静音音频探测 Key 是否有效 |

## 工作原理

1. 主世界脚本(content/bridge.js)读取播放器数据,并**克隆拦截**播放器自己发起的字幕请求响应(timedtext json3 / 直播 webvtt)——播放器请求自带有效签名,避免 2025 年后 YouTube 的 POT 校验导致直接拉字幕为空
2. 隔离世界脚本解析字幕 cue → 经后台 service worker 翻译(Google 接口或自定义 API,SW 请求不受页面 CORS 限制)→ 叠加层按播放进度显示
3. **无字幕时**:service worker 用 tabCapture 捕获标签页音频 → offscreen 文档重采样为 16kHz 单声道 → 每 7 秒开一条火山流式识别 WebSocket 会话(鉴权头由 DNR 规则注入握手)→ 译文按块滚动显示

## 已知局限

- 依赖 YouTube 字幕机制本身,若其改版需跟进
- 直播字幕依赖主播开启「直播自动字幕」,部分直播没有;直播仅显示最新一句,不支持回看对齐
- 语音识别有约 7 秒延迟(分块大小决定),说话间隙过长时字幕会淡化;识别按音频时长计费,建议只看直播/视频时开启
- 免费 Google 接口非官方、无 SLA,需能访问 Google 服务(需代理);重度使用建议配置自定义 API
- 不支持 Shorts 与站外嵌入播放器
- 修改扩展代码后需在 `chrome://extensions/` 点「重新加载」并刷新 YouTube 页面

## 隐私

- 只在你浏览 YouTube 时运行;除翻译请求外不发起任何网络请求
- 自定义 API Key 仅保存在本机 chrome.storage.local
- 非官方扩展,仅用于个人使用
