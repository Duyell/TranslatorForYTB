# TranslatorForYTB

Chrome 扩展:在 YouTube 播放器画面上叠加**日语语音的实时中文翻译字幕**,看日语 Vtuber 录播/直播时不用再「看图猜话」。

- **字幕优先**:YouTube 有自动字幕时直接使用(免费、零延迟)
- **语音识别兜底**:没有字幕时自动切换到火山引擎实时语音识别(ASR),有声音就能出字幕,录播/直播都行(延迟约 7 秒)
- **直播聊天翻译**:评论区评论自动翻译,译文小字附在原文下方(可开关)
- 翻译默认走免费 Google 接口,零配置开箱即用;也可在设置页接入任意 OpenAI 兼容 API(DeepSeek、火山方舟豆包等)
- 译文直接叠加在视频画面下方(双语可关、字号可调),不遮挡控制条

## 安装(开发者模式)

1. 在 GitHub 页面点「**Code → Download ZIP**」下载本仓库,解压到一个**固定的位置**
2. 打开 `chrome://extensions/`,开启右上角「**开发者模式**」
3. 点「**加载已解压的扩展程序**」,选择解压出来的文件夹
4. 固定图标到工具栏;点击图标 = 开关当前 YouTube 标签页的字幕翻译(快捷键 `Alt+Shift+D`,可在 `chrome://extensions/shortcuts` 修改)
5. 右键图标 →「**选项**」打开设置页

> ⚠️ 解压后的文件夹**不要移动、改名或删除**(扩展 ID 与路径绑定,移动后需重新加载)。
> Chrome 偶尔启动时会弹「关闭开发者模式扩展」的安全提示,点「**保留**」即可 —— 这是 Chrome 对个人本地扩展的强制安全设计。

## 使用

- **录播**:打开带日语自动字幕的 Vtuber 视频,字幕自动叠加显示(优先自动字幕,无自动字幕时用人工日语字幕)
- **直播**:打开直播(需主播开启直播自动字幕),几秒后开始滚动显示最新译文
- **无字幕的视频/直播**:自动切换到语音识别(约 7 秒延迟);首次使用会提示「点击工具栏图标一次」完成浏览器授权 —— **点一下图标**即可,同一标签页内之后不用再点
- 图标上的 badge 显示当前标签页的开关状态(绿「开」/灰「关」)

## 设置(右键图标 → 选项)

| 项 | 说明 |
| --- | --- |
| 翻译引擎 | 免费 Google(默认)/ 自定义 OpenAI 兼容 API |
| API Base URL / Key / 模型名 | 自定义引擎三件套。例:DeepSeek `https://api.deepseek.com` + `deepseek-chat`。Key 只保存在本机,不同步云端 |
| 翻译主播语音 | 视频字幕栏总开关(默认开)。关闭后字幕栏完全停用、不启动语音识别(不产生识别费用),评论区翻译照常 |
| 目标语言 | 译文输出语言,默认 `zh-CN`,可填任意语言代码(如 `zh-TW`、`en`、`ko`) |
| 显示日语原文 | 双语开关(默认开) |
| 字号 | 12–32 px,保存即生效 |
| 翻译直播聊天 | 评论区评论翻译(默认开),译文小字附在评论原文下方;聊天翻译走低优先级队列,不影响字幕翻译速度 |
| 语音识别 API Key | 无字幕兜底用。需在[豆包语音控制台](https://console.volcengine.com/speech/app)开通「流式语音识别-大模型」并签发 Key(**火山方舟的 Key 不通用**),按转写时长计费 |
| 识别语言 | 默认 `ja-JP`,留空 = 自动检测 |
| 测试翻译 / 测试识别 Key | 分别实测翻译引擎与语音识别 Key 是否有效 |
| 导出/导入配置 | 重装扩展或换设备时一键备份/恢复全部设置(导出文件包含 API Key 明文,请妥善保管) |

## 工作原理

1. 主世界脚本(content/bridge.js)读取播放器数据,并**克隆拦截**播放器自己发起的字幕请求响应(timedtext json3 / 直播 webvtt)——播放器请求自带有效签名,避免 2025 年后 YouTube 的 POT 校验导致直接拉字幕为空
2. 隔离世界脚本解析字幕 cue → 经后台 service worker 翻译(Google 接口或自定义 API,SW 请求不受页面 CORS 限制)→ 叠加层按播放进度显示
3. **无字幕时**:service worker 用 tabCapture 捕获标签页音频(并原样播回扬声器)→ offscreen 文档重采样为 16kHz 单声道 → 每 7 秒开一条火山流式识别 WebSocket 会话(能量检测裁静音、鉴权头由 DNR 规则注入握手)→ 译文按块滚动显示

## 已知局限

- 依赖 YouTube 字幕机制本身,若其改版需跟进
- 直播字幕依赖主播开启「直播自动字幕」,部分直播没有;直播字幕仅显示最新一条,不支持回看对齐
- 语音识别约 7 秒延迟(分块大小决定);切块边界偶尔会切断词语;识别按音频时长计费,建议只看直播/视频时开启
- 免费 Google 接口非官方、无 SLA,需能访问 Google 服务(需代理);人名/绰号/俚语会被翻成罗马音 —— 介意的话用自定义引擎(如 DeepSeek),人名会音译成中文
- 不支持 Shorts 与站外嵌入播放器
- 修改扩展代码后需在 `chrome://extensions/` 点「重新加载」并刷新 YouTube 页面

## 给其他用户(从 GitHub 安装)

- 本仓库即分发物:按上方「安装」步骤操作即可,**无需打包**
- 每个用户需要自己的密钥:火山引擎语音识别 Key(豆包语音控制台)按音频时长计费;翻译引擎可选免费的 Google(需代理)或自己的 DeepSeek 等 Key
- 现代 Chrome 已屏蔽本地 .crx 拖拽安装,打包成 crx 只对 Edge 用户有意义;如需打包,**`.pem` 私钥绝不能提交到仓库**(本仓库 .gitignore 已排除)
- 想给用户零门槛安装体验:上架 Chrome Web Store(一次性 $5 开发者注册),可发布为「不公开」仅分享链接

## 隐私

- 只在你浏览 YouTube 时运行;除翻译与语音识别请求外不发起任何网络请求
- 所有 API Key 仅保存在本机 chrome.storage.local
- 非官方扩展,仅用于个人使用
